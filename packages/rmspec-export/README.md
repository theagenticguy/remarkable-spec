# rmspec-export

Writers for SVG, PNG and PDF, plus PDF page rasterization.

- Import path: `rmspec.export`
- Workspace dependencies: `rmspec-domain`, `rmspec-render`
- Third-party dependencies: `cairocffi`, `cairosvg`, `pillow`, `pymupdf`

Part of the [remarkable-spec](../../README.md) workspace. The dependency
direction is asserted by `tests/architecture/test_dependency_direction.py`,
not merely documented here.
